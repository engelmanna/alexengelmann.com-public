Niagara Simulation Stage Testing

Unreal Engine recently added "Simulation Stages" to Niagara, which allows for user directed logic to be run on every update of a Niagara particle system. I took some time to experiment wtih the new feature and build out a small prototype of microbes that are attracted or repeled in certain areas based on user input.
