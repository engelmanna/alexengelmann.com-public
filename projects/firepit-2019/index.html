Firepit 2019 Teaser

Torch Technologies hosts an annual "Shark Tank" like event called Fire Pit. For the 2019 event, I was asked to create a teaser video to help drum up interest for the event. I was given the logo and a theme of "sailing ships" and was tasked with coming up with the animation in a week.

The project was created and animated all in Unreal Engine. Keeping it all in UE4 allowed me to quickly iterate on ideas, and stay flexible until the very end. As a bonus, the whole thing takes about 45 seconds to render, so I was able to always pump out full quality previews to the planning committee.

Given the super tight turn around, I built as many of the assets as procedurally as possible. There are a few videos below that illustrate how the paths and icons were build with proceduralism in mind.
